# Schritt für Schritt

## Grundfall einrichten

1. Setzen Sie das Widget **Bild mit Punkten** auf die Seite.
2. Öffnen Sie die Einstellungen des Widgets. Das Fenster zur Bearbeitung der
   Punkte öffnet sich von selbst.
3. Klicken Sie links auf **Bild wählen …** und wählen Sie ein Bild aus der
   Mediathek. Ohne Bild lässt sich kein Punkt setzen.
4. Tragen Sie darunter einen **Alternativtext** ein, der beschreibt, was auf
   dem Bild zu sehen ist.
5. Klicken Sie an die gewünschte Stelle im Bild. Dort entsteht ein neuer
   Punkt, und rechts erscheint sein Formular.
6. Tragen Sie den **Titel** ein. Ohne Titel lässt sich das Fenster nicht mit
   **Übernehmen** schließen — ein entsprechender Hinweis erscheint sowohl am
   Feld als auch unten im Fenster.
7. Tragen Sie optional eine **Beschreibung** ein.
8. Optional: fügen Sie unter dem Feld „Beschreibung“ über **Link
   hinzufügen** ein Ziel hinzu — siehe Abschnitt „Einen Link setzen“ weiter
   unten.
9. Wiederholen Sie die Schritte 5 bis 8 für jeden weiteren Punkt. Ein Bild
   trägt höchstens 20 Punkte.
10. Klicken Sie auf **Übernehmen**.
11. Wählen Sie unter **Darstellung** zwischen „Nummeriert, mit Liste neben
    dem Bild“ und „Punkte, ohne Liste“.
12. Speichern Sie die Seite und prüfen Sie das Ergebnis in der Vorschau.

## Einen Link setzen

1. Klicken Sie im Formular eines Punktes auf **Link hinzufügen**.
2. Wählen Sie unter **Ziel** eine Seite aus der Liste. Ein Link auf eine Seite
   aus dieser Liste erscheint später in einem Fenster über der Seite.
3. Möchten Sie stattdessen eine eigene Adresse eintragen, klicken Sie auf
   **Eigene Adresse eingeben …** und tragen Sie die Adresse in das Feld
   **Adresse** ein. Eine solche Adresse öffnet sich später in einem neuen
   Tab, nicht im Fenster — dafür steht dort der Hinweistext.
4. Über **Stattdessen eine Seite auswählen** kommen Sie von der eigenen
   Adresse zurück zur Liste.
5. Tragen Sie optional eine eigene **Beschriftung des Buttons** ein. Bleibt
   das Feld leer, zeigt der Button „Seite öffnen“.
6. Über **Link entfernen** verschwindet der Link wieder; Titel und
   Beschreibung des Punktes bleiben davon unberührt.

## Punkte verschieben, sortieren und entfernen

1. Um einen Punkt zu verschieben, ziehen Sie ihn im Bild an die neue Stelle.
2. Um die Reihenfolge der Nummerierung zu ändern, wählen Sie den Punkt in der
   Liste rechts aus und klicken Sie auf **Nach oben** oder **Nach unten**.
3. Um einen Punkt zu entfernen, wählen Sie ihn aus und klicken Sie in seinem
   Formular auf **Punkt löschen**.
4. Schließen Sie jede Änderung mit **Übernehmen** ab; über **Abbrechen**
   verwerfen Sie alle Änderungen seit dem letzten Öffnen des Fensters.

## Nachträglich ändern

1. Öffnen Sie die Einstellungen des Widgets erneut. Das Fenster zeigt die
   vorhandenen Punkte und das gewählte Bild.
2. Wählen Sie links in der Liste den zu ändernden Punkt aus und bearbeiten
   Sie sein Formular rechts.
3. Um das Bild auszutauschen, klicken Sie auf **Anderes Bild wählen …**.
   Die Punkte bleiben erhalten; prüfen Sie danach, ob ihre Position auf dem
   neuen Bild noch passt.
4. **Übernehmen**, speichern, in der Vorschau prüfen.

## Wenn etwas nicht funktioniert

1. **Das Widget zeigt nichts an.** Entweder fehlt das Bild, oder es ist noch
   kein Punkt gesetzt. Öffnen Sie die Einstellungen und prüfen Sie beides.
2. **„Übernehmen“ lässt sich nicht anklicken.** Mindestens ein Punkt hat noch
   keinen Titel. Das Fenster nennt unten, wie viele Punkte betroffen sind —
   tragen Sie dort jeweils einen Titel ein.
3. **Die verlinkte Seite erscheint nicht im Fenster, sondern öffnet einen
   neuen Tab.** Das Ziel ist eine selbst eingetragene Adresse, keine Seite aus
   der Liste. Das ist so vorgesehen: fremde Seiten lassen sich oft nicht in
   ein Fenster einbetten. Wählen Sie stattdessen eine Seite aus der Liste,
   wenn sie im Fenster erscheinen soll.
4. **In der Liste der Seiten steht keine einzige Seite, sondern ein Feld für
   eine Adresse.** Die Seitenliste des Systems war beim Öffnen nicht
   erreichbar. Tragen Sie die Adresse von Hand ein oder öffnen Sie das
   Fenster erneut.
