# Schritt für Schritt

## Grundfall einrichten

1. Setzen Sie das Widget **Bild mit Punkten** auf die Seite.
2. Öffnen Sie die Einstellungen des Widgets. Das Vollbild-Fenster **Punkte
   setzen** öffnet sich von selbst; sonst klicken Sie auf **Bild mit Punkten
   bearbeiten**. In der Leiste über dem Bild steht die **Quelle der Punkte**
   auf „Manuell“.
3. Klicken Sie in der Mitte auf **Bild wählen** (oder in der Leiste auf
   **Bild wählen**). Rechts öffnet sich die Mediathek; wählen Sie ein Bild
   oder ziehen Sie es von dort auf die Fläche. Ohne Bild lässt sich kein
   Punkt setzen.
4. Tragen Sie rechts unter **Bildbeschreibung** ein, was auf dem Bild zu
   sehen ist.
5. Klicken Sie an die gewünschte Stelle im Bild. Dort entsteht ein neuer
   Punkt, links erscheint er in der Liste, rechts sein Panel **Punkt 1**.
   Alternativ legt **Neuer Punkt** links einen Punkt in der Bildmitte an.
6. Tragen Sie den **Titel** ein. Ohne Titel übernimmt das Fenster nicht —
   der Hinweis steht gleich am Feld.
7. Tragen Sie optional eine **Beschreibung** ein.
8. Optional: wählen Sie im Abschnitt **Link** ein Ziel — siehe „Einen Link
   setzen“ weiter unten.
9. Wiederholen Sie die Schritte 5 bis 8 für jeden weiteren Punkt. Ein Bild
   trägt höchstens 20 Punkte; die Statuszeile unter dem Bild zählt mit.
10. Wählen Sie in der Leiste rechts unter **Darstellung der Punkte** zwischen
    „Nummern“ (mit Liste neben dem Bild) und „Punkte“ (ohne Liste).
11. Prüfen Sie das Ergebnis über **Desktop**, **Tablet** und **Mobil** im
    Kopf des Fensters.
12. Klicken Sie auf **Übernehmen**, speichern Sie die Seite.

## Ein Icon statt des roten Punkts

Jeder Punkt kann statt des roten Punkts ein eigenes Bild zeigen — etwa ein
Symbol oder ein freigestelltes Foto. Das geht in beiden Modi.

1. Wählen Sie den Punkt aus: im Modus „Manuell“ in der Liste links oder im
   Bild, im Modus „Aus dem Menü“ den platzierten Menüpunkt im Baum oder im
   Bild.
2. Klicken Sie im Abschnitt **Icon** auf das Feld **Medium** („Kein Icon“)
   und wählen Sie ein Bild aus der Mediathek, oder ziehen Sie es aus der
   Mediathek auf den Abschnitt. Transparente PNG- oder SVG-Dateien wirken
   freigestellt am besten.
3. Wählen Sie unter **Größe** zwischen S (32 px), M (48 px, voreingestellt)
   und L (72 px).
4. Wählen Sie unter **Hintergrund**, ob das Bild frei steht (Transparent,
   voreingestellt) oder auf einer runden Fläche in Weiß, MAN-Rot, Anthrazit
   oder Hellgrau — wie der rote Punkt.
5. Über **Icon entfernen** kehrt der rote Punkt zurück.

In der Mediathek finden Sie ein Bild auch, indem Sie seine Adresse (etwa aus
einer Seite kopiert) oder seine ID ins Suchfeld einfügen. Unter dem
Filter-Symbol lässt sich die Auswahl auf eine **Sammlung** beschränken.

## Einen Link setzen

1. Wählen Sie im Panel des Punktes im Abschnitt **Link** unter **Ziel** eine
   Seite aus der Liste. Ein Link auf eine Seite aus dieser Liste erscheint
   später in einem Fenster über der Seite.
2. Möchten Sie stattdessen eine eigene Adresse eintragen, wählen Sie
   **Eigene Adresse eingeben …** und tragen Sie die Adresse in das Feld
   **Adresse** ein. Eine solche Adresse öffnet sich später in einem neuen
   Tab, nicht im Fenster — dafür steht dort der Hinweistext.
3. Über **Stattdessen eine Seite wählen** kommen Sie von der eigenen Adresse
   zurück zur Liste.
4. Tragen Sie optional eine eigene **Beschriftung des Buttons** ein. Bleibt
   das Feld leer, zeigt der Button „Seite öffnen“.
5. Über **Kein Link** (bzw. **Link entfernen** bei einer eigenen Adresse)
   verschwindet der Link wieder; Titel und Beschreibung des Punktes bleiben
   davon unberührt.

## Punkte verschieben, sortieren und entfernen

1. Um einen Punkt zu verschieben, ziehen Sie ihn im Bild an die neue Stelle.
   Mit den Pfeiltasten verschieben Sie den gewählten Punkt um ein Prozent.
2. Die Reihenfolge der Liste links ist die Nummerierung. Ziehen Sie einen
   Punkt am Griff an eine andere Stelle, oder nutzen Sie über dem Panel
   rechts **Punkt nach oben** und **Punkt nach unten**.
3. **Punkt duplizieren** legt eine Kopie gleich dahinter an, leicht versetzt.
4. **Punkt löschen** entfernt den gewählten Punkt.
5. Schließen Sie mit **Übernehmen** ab; **Rückgängig** im Kopf nimmt einzelne
   Schritte zurück, **Abbrechen** verwirft alle Änderungen seit dem letzten
   Übernehmen.

## Nachträglich ändern

1. Öffnen Sie die Einstellungen des Widgets erneut. Das Fenster zeigt die
   vorhandenen Punkte und das gewählte Bild.
2. Wählen Sie links in der Liste den zu ändernden Punkt aus und bearbeiten
   Sie ihn rechts.
3. Um das Bild auszutauschen, klicken Sie in der Leiste auf **Bild ändern**.
   Die Punkte bleiben erhalten; prüfen Sie danach, ob ihre Position auf dem
   neuen Bild noch passt. Ein Klick auf den Namen des Bildes in der Leiste
   zeigt rechts wieder Bild und Bildbeschreibung.
4. **Übernehmen**, speichern, in der Vorschau prüfen.

## Im Content Designer

Im Content Designer funktioniert alles genauso: das Bild wird im Fenster aus
der Mediathek gewählt, nicht im Formular. Bei Widgets aus früheren Fassungen
kann das Fenster manche Einstellungen nicht aus dem Formular lesen; es nennt
sie in einem Hinweis und lässt sie unverändert, bis Sie sie im Fenster
ändern.

## Modus „Aus dem Menü“: Menüpunkte platzieren

1. Öffnen Sie das Fenster und stellen Sie in der Leiste die **Quelle der
   Punkte** auf „Aus dem Menü“.
2. Wählen Sie rechts im Panel **Menü** unter **Startpunkt** den Menüpunkt,
   dessen Unterpunkte auf dem Bild liegen sollen. Steht er nicht in der
   Liste, wählen Sie **Andere Menü-ID eingeben …** und fügen die Adresse der
   Seite ein. Links erscheinen die **Menü-Ebenen**.
3. Legen Sie unter **Tiefe** fest, wie tief das Menü reicht (voreingestellt
   3 Ebenen), und unter **Klick auf einen Punkt mit Unterpunkten**, ob ein
   Klick ins Untermenü wechselt (voreingestellt) oder die Seite öffnet.
4. Wählen Sie unter **Bild der Ebene** (oder in der Leiste über **Bild
   wählen**) das Bild der Startebene.
5. Wählen Sie links einen Unterpunkt ohne eigene Unterpunkte und klicken Sie
   an die gewünschte Stelle im Bild. Dort entsteht sein Punkt; im Baum steht
   der Eintrag danach auf „Punkt gesetzt“.
6. Ein Eintrag **mit** Unterpunkten zeigt beim Anklicken links seine eigene
   Ebene. Seinen Punkt auf der Ebene darüber setzen Sie über **Punkt für …
   setzen** im Panel **Menü** — oder Sie fassen ihn im Bild an, wenn er
   schon liegt.
7. Um einen Punkt zu versetzen, ziehen Sie ihn oder wählen Sie den Eintrag
   und klicken Sie an die neue Stelle. **Punkt löschen** über dem Panel nimmt
   ihn wieder vom Bild.
8. Für eine tiefere Ebene wählen Sie links den Eintrag mit Unterpunkten,
   geben Sie ihr unter **Bild der Ebene** ein Bild und setzen Sie die Punkte
   wie in Schritt 5. Ohne eigenes Bild zeigt die Ebene später das Bild der
   Ebene darüber.
9. Klicken Sie auf **Übernehmen**, speichern Sie die Seite und prüfen Sie
   das Ergebnis in der Vorschau.

## Wenn etwas nicht funktioniert

1. **Das Widget zeigt nichts an.** Entweder fehlt das Bild, oder es ist noch
   kein Punkt gesetzt. Öffnen Sie die Einstellungen und prüfen Sie beides —
   die Vorschau **Desktop** sagt es auch.
2. **„Übernehmen“ übernimmt nicht, der Status ist rot.** Mindestens ein
   Punkt hat noch keinen Titel. Der Status nennt ihn, links ist er als
   „Titel fehlt“ markiert und rechts geöffnet — tragen Sie dort einen Titel
   ein.
3. **Die verlinkte Seite erscheint nicht im Fenster, sondern öffnet einen
   neuen Tab.** Das Ziel ist eine selbst eingetragene Adresse, keine Seite aus
   der Liste. Das ist so vorgesehen: fremde Seiten lassen sich oft nicht in
   ein Fenster einbetten. Wählen Sie stattdessen eine Seite aus der Liste,
   wenn sie im Fenster erscheinen soll.
4. **Unter „Ziel“ steht keine Liste, sondern ein Feld für eine Adresse.** Die
   Seitenliste des Systems war beim Öffnen nicht erreichbar. Tragen Sie die
   Adresse von Hand ein oder öffnen Sie das Fenster erneut.
5. **Im Modus „Aus dem Menü“ steht links der Hinweis, zuerst einen
   Startpunkt zu wählen.** Unter **Startpunkt** ist noch nichts gewählt.
6. **Links stehen Einträge als Fehler „Nicht mehr im Menü“.** Der zugehörige
   Menüpunkt wurde gelöscht, verborgen, im Menü verschoben oder liegt
   tiefer, als unter **Tiefe** eingestellt. Auf der Seite erscheinen diese
   Punkte nicht. Wählen Sie den Eintrag und löschen Sie den Punkt, oder
   erhöhen Sie die Tiefe.
7. **Im Panel steht „Aus dem Dialog nicht lesbar: …“.** Das Widget stammt
   aus einer früheren Fassung, und das Formular verrät diese Einstellungen
   nicht. Das Widget behält dafür seine bisherigen Werte; stellen Sie sie im
   Fenster ein, wenn Sie sie ändern möchten.
8. **Die Einstellungen sind nach dem Speichern der Seite wieder weg.** Das
   Widget ist in der Instanz noch ohne das Feld `config` registriert. Die
   Registrierung muss aktualisiert werden (Aufgabe der Administration).
