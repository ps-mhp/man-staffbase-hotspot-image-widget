# Bild mit Punkten

Dieses Widget zeigt ein Bild, auf dem einzelne Stellen als **Punkte**
markiert sind — etwa Stationen auf einem Übersichtsplan, Personen auf einem
Gruppenfoto oder Bauteile auf einer Skizze. Zu jedem Punkt gehören ein Titel,
wahlweise eine Beschreibung und wahlweise ein Link auf eine Seite.

Alle Punkte werden im selben Fenster gepflegt, das sich beim Öffnen der
Einstellungen von selbst zeigt: Bild wählen, in das Bild klicken, um einen
Punkt zu setzen, Titel und die übrigen Angaben eintragen.

## Zwei Modi

Unter **Modus** steht zur Wahl, woher die Punkte kommen:

- **Manuell** — jeder Punkt bekommt einen eigenen Titel, eine Beschreibung
  und auf Wunsch einen Link. So wie bisher.
- **Menü** — Sie wählen einen Menüpunkt der App. Seine Unterpunkte lassen
  sich als Punkte auf einem Bild platzieren — und für jede tiefere
  Menüebene auf einem eigenen Bild. Titel und Ziele kommen direkt aus dem
  Menü: wird ein Menüpunkt umbenannt, heißt auch sein Punkt sofort anders.
  Neben dem Bild steht das Menü zum Blättern.

Die Punkte des jeweils anderen Modus bleiben beim Wechsel erhalten.

## Die beiden Darstellungen im Modus „Manuell“

Unter **Darstellung** steht eine von zwei Varianten zur Wahl:

- **Nummeriert, mit Liste neben dem Bild** — jeder Punkt trägt eine Zahl, und
  neben dem Bild steht eine aufklappbare Liste mit allen Titeln. Ein Klick auf
  einen Punkt oder auf den passenden Listeneintrag klappt dessen Text auf.
  Sinnvoll ab etwa fünf Punkten und überall dort, wo Lesende die Titel auch
  ohne Suchen im Bild sehen sollen.
- **Punkte, ohne Liste** — die Punkte erscheinen ohne Zahl, und es gibt keine
  Liste daneben. Ein Klick auf einen Punkt öffnet ein kleines Fenster direkt
  daneben mit Titel, Beschreibung und Link. Sinnvoll bei wenigen Punkten und
  wenn das Bild für sich stehen soll, ohne dass gleich eine Liste danebensteht.

## Was Leser:innen sehen

- Ohne Bild oder ohne mindestens einen Punkt zeigt das Widget gar nichts —
  keinen leeren Rahmen, kein Platzhalterbild.
- In der Darstellung „Punkte“ öffnet sich das Fenster mit dem Text am Punkt
  selbst; auf schmalen Bildschirmen (unter 768 Pixel Breite) erscheint es
  stattdessen mittig im Bildschirm, mit einer Abdunklung dahinter.
- In der Darstellung „Nummeriert“ wird der zugehörige Punkt im Bild
  hervorgehoben, sobald der Mauszeiger über einem Listeneintrag steht oder ein
  Eintrag aufgeklappt ist: er wird größer, die übrigen Punkte treten zurück.
  Auf schmalen Bildschirmen erscheinen die Punkte klein und ohne Zahl, damit
  sie sich auch bei vielen Stellen nicht überdecken; welcher Punkt zu welchem
  Eintrag gehört, zeigt das Antippen in der Liste.
- Führt ein Punkt zu einer Seite des Systems, erscheint darunter ein Button.
  Ein Klick darauf öffnet die Seite in einem Fenster über der aktuellen Seite;
  bei einer selbst eingetragenen Adresse öffnet derselbe Button stattdessen
  einen neuen Tab.
- Die Bedienung funktioniert auch ohne Maus: mit der Tabulatortaste lässt sich
  von Punkt zu Punkt springen, mit der Eingabetaste öffnen, mit Escape
  schließen.

## Was Leser:innen im Modus „Menü“ sehen

- Links das Bild der gezeigten Menüebene mit roten Punkten ohne Zahl, rechts
  daneben das Menü — auf schmalen Bildschirmen darunter. Das Menü zeigt eine
  Ebene zur Zeit: ein Pfeil führt eine Ebene tiefer, der Zurück-Knopf oben
  wieder hinauf, auf dem Telefon auch ein Wischen nach rechts.
- Wer im Menü in eine Ebene blättert, sieht deren Bild mit den Punkten
  ihrer Unterpunkte. Hat eine Ebene kein eigenes Bild, bleibt das Bild der
  Ebene darüber stehen.
- Steht der Mauszeiger auf einem Punkt, erscheint der Name des Menüpunkts,
  und im Menü wird der passende Eintrag markiert. Umgekehrt hebt ein Eintrag
  unter dem Mauszeiger seinen Punkt hervor.
- Ein Klick auf einen Punkt, der selbst Unterpunkte hat, wechselt in dieses
  Untermenü — oder, je nach Einstellung, öffnet seine Seite. Punkte ohne
  Unterpunkte öffnen immer ihre Seite.
- Jede:r sieht nur Punkte zu Menüpunkten, die er oder sie auch im Menü der
  App sieht. Im Menü verborgene Einträge erscheinen nicht.
