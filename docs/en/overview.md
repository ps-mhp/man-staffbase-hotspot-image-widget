# Image with dots

This widget shows an image on which individual digits are displayed as **dots** 
— for example, stations on an overview plan, people on a
group photo or components on a sketch. Each point has a title, 
either a description and optionally a link to a page. 

All points are maintained in the same window that appears when the
settings by itself: select image, click in the image to view a
period, enter the title and the other information. 

## The two representations

Under **Presentation** you can choose from one of two variants: 

- **Numbered, with list next to the picture** — each dot has a number, and
  next to the picture is a fold-down list of all titles. Click on
  a point or the corresponding list entry opens its text. 
  Useful from about five points and wherever readers read the titles
  without searching in the picture. 
- **Points, without list** — the dots appear without a number, and there are no
  List next to it. Clicking on a dot opens a small window directly
  next to it with title, description and link. Useful for a few points and
  if the picture should stand on its own without a list next to it. 

## What readers see

- Without an image or without at least one point, the widget doesn't show anything at all — 
  no empty frame, no placeholder image. 
- In the "Points" view, the window with the text at the point opens
  itself; on narrow screens (less than 768 pixels wide) it appears
  instead, in the middle of the screen, with a darkening behind it. 
- If a dot leads to a page of the system, a button appears underneath. 
  Clicking on it opens the page in a window above the current page; 
  for a self-entered address, the same button opens instead
  a new tab. 
- The operation also works without a mouse: with the Tab key you can
  jump from point to point, open with the enter key, with Escape
  close.
