## Établir un lien

1. Cliquez sur **Ajouter un lien** sous forme de point. 
2. Sous **Destination**, sélectionnez une page de la liste. Un lien vers une page
   cette liste apparaîtra plus tard dans une fenêtre au-dessus de la page. 
3. Si vous souhaitez entrer votre propre adresse, cliquez sur
   **Saisissez votre propre adresse ...** et entrez l’adresse dans le champ
   **Adresse**. Une telle adresse s’ouvrira plus tard dans un nouveau
   Tab, pas dans la fenêtre — c’est à ça que sert le texte d’information. 
4. En **sélectionnant une page à la place**, vous viendrez de la vôtre
   Adresser retour à la liste. 
5. Éventuellement, entrez votre propre **étiquette du bouton**. Restes
   le champ est vide, le bouton affiche « Ouvrir la page ». 
6. Via **Supprimer le lien**, le lien disparaît à nouveau ; Titre et
   La description du point reste indifférente.
