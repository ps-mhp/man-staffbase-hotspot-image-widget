# Étape par étape

## Configuration de base

1. Placez le widget **Image avec des points** sur la page.
2. Ouvrez les paramètres du widget. La fenêtre plein écran **Placer des points
  ** s'ouvre automatiquement ; sinon, cliquez sur **Modifier l'image avec des points
  **. Dans la barre au-dessus de l'image, la **source des points**
   est réglée sur « Manuel ».
3. Cliquez au centre sur **Sélectionner une image** (ou sur
   **Sélectionner une image** dans la barre). La médiathèque s’ouvre à droite ; sélectionnez une image
   ou faites-la glisser depuis la médiathèque vers la zone de travail. Sans image, il n’est pas possible de
   placer un point.
4. À droite, sous **Description de l’image**, indiquez ce qui est
   visible sur l’image.
5. Cliquez à l’endroit souhaité dans l’image. Un nouveau
   point y apparaît ; il s’affiche dans la liste à gauche et son panneau **Point 1** à droite.
   Sinon, **Nouveau point** crée un point au centre de l’image à gauche.
6. Saisissez le **Titre**. Sans titre, la fenêtre ne se valide pas —
   la remarque apparaît juste à côté du champ.
7. Saisissez éventuellement une **Description**.
8. Facultatif : dans la section **Lien**, sélectionnez une destination — voir « Créer un lien
   » ci-dessous.
9. Répétez les étapes 5 à 8 pour chaque point supplémentaire. Une image
   peut comporter au maximum 20 points ; la barre d’état sous l’image est comptabilisée.
10. Dans la barre de droite, sous **Affichage des points**, choisissez entre
    « Numéros » (avec une liste à côté de l’image) et « Points » (sans liste).
11. Vérifiez le résultat via **Bureau**, **Tablette** et **Mobile** en
    haut de la fenêtre.
12. Cliquez sur **Appliquer**, puis enregistrez la page.

## Une icône à la place du point rouge

Chaque point peut afficher sa propre image à la place du point rouge — par exemple une
symbole ou une photo recadrée. Cela fonctionne dans les deux modes.

1. Sélectionnez le point : en mode « Manuel », dans la liste à gauche ou dans l’
  image ; en mode « À partir du menu », l’élément de menu placé dans l’arborescence ou dans l’
  image.
2. Dans la section **Icône**, cliquez sur le champ **Support** (« Pas d’icône »)
   et sélectionnez une image dans la médiathèque, ou faites-la glisser depuis la
   médiathèque vers la section. Les fichiers PNG ou SVG transparents donnent
   le meilleur rendu lorsqu’ils sont détachés.
3. Sous **Taille**, choisissez entre S (32 px), M (48 px, par défaut)
   et L (72 px).
4. Sous **Arrière-plan**, choisissez si l’image doit être en fond perdu (transparente,
   par défaut) ou sur un fond rond de couleur blanche, rouge MAN, anthracite
   ou gris clair — comme le point rouge.
5. Cliquez sur **Supprimer l’icône** pour faire réapparaître le point rouge.

Dans la médiathèque, vous pouvez également trouver une image en saisissant son adresse (copiée par exemple à partir
d’une page) ou son identifiant dans le champ de recherche. Sous l’
icône de filtre, vous pouvez limiter la sélection à une **collection**.

## Créer un lien

1. Dans le panneau du point, dans la section **Lien**, sous **Cible**, sélectionnez une
   page dans la liste. Un lien vers une page de cette liste apparaîtra
   ensuite dans une fenêtre au-dessus de la page.
2. Si vous souhaitez plutôt saisir votre propre adresse, sélectionnez
   **Saisir votre propre adresse…** et saisissez l’adresse dans le champ
   **Adresse**. Une telle adresse s’ouvrira ensuite dans un nouvel
   onglet, et non dans la fenêtre — c’est ce qu’indique le texte d’aide.
3. En cliquant sur **Choisir une page à la place**, vous revenez de l’adresse personnalisée
   à la liste.
4. Vous pouvez, si vous le souhaitez, saisir votre propre **libellé du bouton**. Si
   le champ reste vide, le bouton affiche « Ouvrir la page ».
5. En cliquant sur **Pas de lien** (ou **Supprimer le lien** s’il s’agit de votre propre adresse),
   le lien disparaît ; le titre et la description de l’élément ne sont
   pas modifiés.

## Déplacer, trier et supprimer des éléments

1. Pour déplacer un élément, faites-le glisser dans la fenêtre vers son nouvel emplacement.
   Les touches fléchées vous permettent de déplacer l’élément sélectionné d’un pour cent.
2. L’ordre de la liste à gauche correspond à la numérotation. Faites glisser un
   élément par sa poignée vers un autre emplacement, ou utilisez les boutons
   **Élément vers le haut** et **Élément vers le bas** situés au-dessus du panneau
   de droite.
3. **Dupliquer l'élément** crée une copie juste derrière, légèrement décalée.
4. **Supprimer le point** supprime le point sélectionné.
5. Validez avec **Appliquer** ; **Annuler** en haut de la fenêtre permet d’annuler des
   étapes individuelles, tandis que **Annuler tout** rejette toutes les modifications effectuées depuis la dernière
   validation.

## Modifier a posteriori

1. Ouvrez à nouveau les paramètres du widget. La fenêtre affiche les
   points existants et l’image sélectionnée.
2. Sélectionnez dans la liste de gauche le point à modifier et modifiez-le
   à droite.
3. Pour remplacer l’image, cliquez sur **Changer d’image** dans la barre.
   Les éléments sont conservés ; vérifiez ensuite si leur position sur la
   nouvelle image est toujours correcte. Un clic sur le nom de l’image dans la barre
   affiche à nouveau l’image et sa description à droite.
4. **Appliquer**, enregistrer, vérifier dans l’aperçu.

## Dans le Content Designer

Dans le Content Designer, tout fonctionne exactement de la même manière : l’image est sélectionnée dans la fenêtre à partir
de la médiathèque, et non dans le formulaire. Pour les widgets issus de versions antérieures,
la fenêtre ne peut pas lire certains paramètres du formulaire ; elle les mentionne
dans une note d’avertissement et les laisse inchangés jusqu’à ce que vous les
modifiiez dans la fenêtre.

## Mode « À partir du menu » : placer des éléments de menu

1. Ouvrez la fenêtre et réglez la **Source des
   éléments** sur « À partir du menu » dans la barre.
2. À droite dans le panneau **Menu**, sous **Point de départ**, sélectionnez l’élément de menu
   dont les sous-éléments doivent apparaître sur l’image. S’il ne figure pas dans la
   liste, sélectionnez **Saisir un autre ID de menu…** et insérez l’adresse de la
   page. Les **niveaux de menu** s’affichent à gauche.
3. Sous **Profondeur**, définissez la profondeur du menu (par défaut
   3 niveaux), et sous **Clic sur un élément comportant des sous-éléments**, indiquez si un
   clic ouvre le sous-menu (par défaut) ou la page.
4. Sous **Image du niveau** (ou dans la barre au-dessus de **Sélectionner une image**),
   sélectionnez l’image du niveau de départ.
5. Sélectionnez à gauche un sous-élément ne comportant pas de sous-éléments et cliquez
   à l’endroit souhaité dans l’image. Un point y apparaîtra ; dans l’arborescence,
   l’entrée indiquera alors « Point défini ».
6. Une entrée **comportant** des sous-éléments affiche son propre
   niveau lorsque vous cliquez dessus à gauche. Vous pouvez placer son point sur le niveau supérieur via **Placer un point pour…
   ** dans le panneau **Menu** — ou le sélectionner dans l’image s’il
   s’y trouve déjà.
7. Pour déplacer un point, faites-le glisser ou sélectionnez l’entrée
   puis cliquez à l’emplacement souhaité. La commande **Supprimer le point** au-dessus du panneau permet
   de le retirer de l’image.
8. Pour créer un niveau plus profond, sélectionnez à gauche l’entrée comportant des sous-points,
   attribuez-lui une image sous **Image du niveau** et placez les points
   comme à l’étape 5. Sans image propre, le niveau affichera ensuite l’image du
   niveau supérieur.
9. Cliquez sur **Appliquer**, enregistrez la page et vérifiez
   le résultat dans l’aperçu.

## Si quelque chose ne fonctionne pas

1. **Le widget n’affiche rien.** Soit l’image manque, soit aucun
   point n’a encore été défini. Ouvrez les paramètres et vérifiez ces deux éléments —
   l’aperçu **Bureau** vous le signale également.
2. **« Appliquer » ne fonctionne pas, le statut est rouge.** Au moins un
   point n’a pas encore de titre. Le statut l’indique : à gauche, il est marqué
   « Titre manquant » et à droite, il est ouvert — saisissez-y un titre
  .
3. **La page liée n’apparaît pas dans la fenêtre, mais s’ouvre dans un
   nouvel onglet.** La destination est une adresse que vous avez saisie vous-même, et non une page de
   la liste. C’est normal : les pages externes ne peuvent souvent pas être
   intégrées dans une fenêtre. Sélectionnez plutôt une page dans la liste
   si vous souhaitez qu’elle s’affiche dans la fenêtre.
4. **Sous « Destination », il n’y a pas de liste, mais un champ destiné à saisir une adresse.** La
   liste des pages du système n’était pas accessible à l’ouverture. Saisissez l’
   adresse manuellement ou rouvrez la fenêtre.
5. **En mode « À partir du menu », une remarque à gauche indique de sélectionner d’abord un
   point de départ.** Sous **Point de départ**, rien n’est encore sélectionné.
6. **À gauche, des entrées indiquent l’erreur « N’apparaît plus dans le menu ».** L’option de menu correspondante
   a été supprimée, masquée, déplacée dans le menu ou se trouve
   à un niveau plus profond que celui défini sous **Profondeur**. Ces
   éléments n’apparaissent pas sur la page. Sélectionnez l’entrée et supprimez l’élément, ou
   augmentez la profondeur.
7. **Le panneau affiche « Non lisible depuis la boîte de dialogue : … ».** Le widget provient
   d’une version antérieure, et le formulaire ne révèle pas ces paramètres
  . Le widget conserve toutefois ses valeurs précédentes ; configurez-les dans la
   fenêtre si vous souhaitez les modifier.
8. **Les paramètres disparaissent après l’enregistrement de la page.** Le
   widget est encore enregistré dans l’instance sans le champ `config`. L’
  enregistrement doit être mis à jour (tâche relevant de l’administration).
