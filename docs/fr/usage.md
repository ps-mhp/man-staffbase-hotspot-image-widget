# Étape par étape

## Configurer le cas de base

1. Placez le widget **Image avec des points** sur la page.
2. Ouvrez les paramètres du widget. La fenêtre **Image avec
   des points** s'ouvre automatiquement ; sinon, cliquez sur **Image avec des points
   modifier…**. En haut, le **Mode** est réglé sur « Manuel ».
3. Cliquez à gauche sur **Sélectionner une image…** et choisissez une image dans la
   médiathèque. Sans image, il n’est pas possible de placer de point.
4. Saisissez ci-dessous un **texte alternatif** décrivant ce qui est
   visible sur l’image.
5. Cliquez à l’endroit souhaité dans l’image. Un nouveau
   point apparaît à cet endroit, et son formulaire s’affiche à droite.
6. Saisissez le **titre**. Sans titre, il n’est pas possible de fermer la fenêtre avec
   **Appliquer** — une remarque à ce sujet s’affiche à la fois dans le
   champ et en bas de la fenêtre.
7. Saisissez éventuellement une **description**.
8. Facultatif : sous le champ « Description », ajoutez une destination via **Ajouter un lien
   ** — voir la section « Créer un lien » plus
   bas.
9. Répétez les étapes 5 à 8 pour chaque point supplémentaire. Une image
   peut comporter au maximum 20 points.
10. En haut, sous **Affichage**, choisissez entre « Numéroté, avec liste
    à côté de l’image » et « Puces, sans liste ».
11. Cliquez sur **Appliquer**.
12. Enregistrez la page et vérifiez le résultat dans l’aperçu.

## Une image personnalisée à la place du point rouge

Chaque point peut afficher une image personnalisée à la place du point rouge — par exemple une
icône ou une photo recadrée. Cela fonctionne dans les deux modes.

1. Sélectionnez le point : en mode « Manuel » dans la liste de droite, en
   mode « Menu », l'élément de menu placé dans la liste des sous-éléments.
2. Sous **Image à la place du point**, cliquez sur **Choisir une image personnalisée…** et
   sélectionnez une image dans la médiathèque. Les fichiers PNG ou SVG transparents
   donnent le meilleur résultat lorsqu’ils sont détachés.
3. Sous **Taille**, choisissez entre S (32 px), M (48 px, par défaut)
   et L (72 px).
4. Sous **Arrière-plan**, choisissez si l’image doit être isolée (transparente,
   par défaut) ou placée sur un fond rond de couleur blanche, rouge MAN, anthracite
   ou gris clair — comme le point rouge.
5. Cliquez sur **Supprimer l’image** pour faire réapparaître le point rouge.

Dans la médiathèque, vous pouvez également trouver une image en saisissant son adresse (copiée par exemple à partir
d’une page) ou son identifiant dans le champ de recherche. Sous l’
icône de filtre, vous pouvez limiter la sélection à une **collection**.

## Créer un lien

1. Dans le formulaire d’un point, cliquez sur **Ajouter un lien**.
2. Sous **Cible**, sélectionnez une page dans la liste. Un lien vers une page
   de cette liste apparaîtra ensuite dans une fenêtre au-dessus de la page.
3. Si vous souhaitez plutôt saisir votre propre adresse, cliquez sur
   **Saisir votre propre adresse…** et saisissez l’adresse dans le champ
   **Adresse**. Une telle adresse s’ouvrira ensuite dans un nouvel
   onglet, et non dans la fenêtre — c’est ce qu’indique le texte d’aide.
4. En cliquant sur **Sélectionner une page à la place**, vous revenez de votre
   propre adresse à la liste.
5. Vous pouvez, si vous le souhaitez, saisir un **libellé du bouton**. Si
   le champ reste vide, le bouton affiche « Ouvrir la page ».
6. En cliquant sur **Supprimer le lien**, le lien disparaît ; le titre et la
   description de l’élément ne sont pas modifiés.

## Déplacer, trier et supprimer des éléments

1. Pour déplacer un élément, faites-le glisser dans la vue vers son nouvel emplacement.
2. Pour modifier l’ordre de la numérotation, sélectionnez l’élément dans la
   liste de droite et cliquez sur **Vers le haut** ou **Vers le bas**.
3. Pour supprimer un élément, sélectionnez-le et cliquez sur **Supprimer l’élément**
   dans son formulaire.
4. Validez chaque modification en cliquant sur **Appliquer** ; cliquez sur **Annuler**
   pour rejeter toutes les modifications effectuées depuis la dernière ouverture de la fenêtre.

## Modifier ultérieurement

1. Ouvrez à nouveau les paramètres du widget. La fenêtre affiche les
   points existants et l’image sélectionnée.
2. Sélectionnez dans la liste de gauche le point à modifier et modifiez
   son formulaire à droite.
3. Pour remplacer l’image, cliquez sur **Choisir une autre image…**.
   Les points sont conservés ; vérifiez ensuite si leur position sur la
   nouvelle image est toujours correcte.
4. **Appliquer**, enregistrer, vérifier dans l’aperçu.

## Dans le Content Designer

Dans le Content Designer, tout fonctionne exactement de la même manière : l’image est sélectionnée dans la fenêtre à partir
de la médiathèque, et non dans le formulaire.

## Mode « Menu » : placer les éléments de menu

1. Ouvrez la fenêtre **Image avec points** et réglez le
   **mode** en haut sur « Menu ».
2. Sous **Point de départ dans le menu**, sélectionnez l’élément de menu dont
   les sous-éléments doivent apparaître sur l’image. S’il ne figure pas dans la liste,
   sélectionnez **Saisir un autre ID de menu…** et saisissez l’adresse de la page
  . Le menu se charge immédiatement.
3. Sous **Niveaux**, définissez le nombre de niveaux du menu (par défaut
   3), et sous **Clic sur un point comportant des sous-éléments**, indiquez si un clic
   ouvre le sous-menu (par défaut) ou la page.
4. Sous **Niveau** figure le niveau de départ. À gauche, sélectionnez votre image dans la médiathèque à l’aide de **Sélectionner
   une image…**.
5. Sélectionnez un sous-élément à droite et cliquez à l’endroit souhaité
   dans l’image. Un point y apparaît ; dans la liste, l’entrée est
   est alors marquée « sur l’image ». Répétez l’opération pour chaque
   sous-rubrique supplémentaire.
6. Pour déplacer un point, faites-le glisser ou sélectionnez l’entrée
   puis cliquez à l’emplacement souhaité. **Supprimer le point** le fait disparaître
   de l’image.
7. Pour créer un niveau inférieur, cliquez sur **›** à droite de la sous-rubrique
   ou sélectionnez le niveau en haut. Choisissez votre image et placez les
   points comme à l’étape 5. Sans image propre, le niveau affichera plus tard l’image
   du niveau supérieur.
8. Cliquez sur **Appliquer**, enregistrez la page et vérifiez
   le résultat dans l’aperçu.

## Si quelque chose ne fonctionne pas

1. **Le widget n’affiche rien.** Soit l’image manque, soit aucun
   point n’a encore été placé. Ouvrez les paramètres et vérifiez ces deux éléments.
2. **Il est impossible de cliquer sur « Appliquer ».** Au moins un point n’a pas encore
   de titre. La fenêtre indique en bas le nombre de points concernés —
   saisissez-y un titre pour chacun d’entre eux.
3. **La page liée n’apparaît pas dans la fenêtre, mais s’ouvre dans un
   nouvel onglet.** La destination est une adresse que vous avez saisie vous-même, et non une page de
   la liste. C’est normal : les pages externes ne peuvent souvent pas être
   intégrées dans une fenêtre. Sélectionnez plutôt une page dans la liste,
   si vous souhaitez qu’elle s’affiche dans la fenêtre.
4. **La liste des pages ne contient aucune page, mais un champ destiné à
   saisir une adresse.** La liste des pages du système n’était pas
   accessible à l’ouverture. Saisissez l’adresse manuellement ou rouvrez la
   fenêtre.
5. **En mode « Menu », un message dans la fenêtre indique de sélectionner d’abord un point de départ
  .** Sous **Point de départ dans le menu**, rien n’est encore sélectionné.
6. **La fenêtre affiche des éléments sous « Plus dans le menu ».** L’élément de
   menu correspondant a été supprimé, masqué, déplacé dans le menu ou se trouve
   à un niveau inférieur à celui défini sous **Niveaux**. Ces éléments n’apparaissent pas sur la page.
   Supprimez-les à cet endroit ou augmentez le nombre de niveaux.
7. **Les paramètres disparaissent après l’enregistrement de la page.** Le
   widget est encore enregistré dans l’instance sans le champ `config`. L’
  enregistrement doit être mis à jour (tâche relevant de l’administration).
