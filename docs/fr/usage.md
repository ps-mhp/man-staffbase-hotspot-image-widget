# Étape par étape

## Configurer le cas de base

1. Placez le widget **Image avec des points** sur la page.
2. Ouvrez les paramètres du widget. La fenêtre permettant de modifier les
   points s'ouvre automatiquement.
3. Cliquez à gauche sur **Sélectionner une image…** et choisissez une image dans la
   médiathèque. Il n'est pas possible de placer un point sans image.
4. Saisissez ci-dessous un **texte alternatif** décrivant ce qui est
   visible sur l’image.
5. Cliquez à l’endroit souhaité sur l’image. Un nouveau
   point apparaît à cet endroit, et son formulaire s’affiche à droite.
6. Saisissez le **titre**. Sans titre, il n’est pas possible de fermer la fenêtre avec
   **Appliquer** — une remarque à ce sujet s’affiche à la fois dans le
   champ et en bas de la fenêtre.
7. Vous pouvez, si vous le souhaitez, saisir une **description**.
8. Facultatif : sous le champ « Description », ajoutez une destination via **Ajouter un lien**
   — voir la section « Insérer un lien » plus
   bas.
9. Répétez les étapes 5 à 8 pour chaque point supplémentaire. Une image
   peut comporter au maximum 20 points.
10. Cliquez sur **Appliquer**.
11. Sous **Affichage**, choisissez entre « Numéroté, avec liste à côté
    de l’image » et « Puces, sans liste ».
12. Enregistrez la page et vérifiez le résultat dans l’aperçu.

## Insérer un lien

1. Dans le formulaire d’un point, cliquez sur **Ajouter un lien**.
2. Sous **Cible**, sélectionnez une page dans la liste. Un lien vers une page
   de cette liste apparaîtra ensuite dans une fenêtre au-dessus de la page.
3. Si vous souhaitez plutôt saisir votre propre adresse, cliquez sur
   **Saisir votre propre adresse…** et saisissez l’adresse dans le champ
   **Adresse**. Une telle adresse s’ouvrira ensuite dans un nouvel
   onglet, et non dans la fenêtre — c’est ce qu’indique le texte d’aide.
4. En cliquant sur **Sélectionner une page à la place**, vous revenez de votre
   propre adresse à la liste.
5. Vous pouvez, si vous le souhaitez, saisir un **libellé du bouton**. Si
   le champ reste vide, le bouton affiche « Ouvrir la page ».
6. En cliquant sur **Supprimer le lien**, le lien disparaît ; le titre et la
   description de l’élément ne sont pas modifiés.

## Déplacer, trier et supprimer des éléments

1. Pour déplacer un élément, faites-le glisser dans la vue vers son nouvel emplacement.
2. Pour modifier l’ordre de la numérotation, sélectionnez l’élément dans la
   liste de droite et cliquez sur **Vers le haut** ou **Vers le bas**.
3. Pour supprimer un élément, sélectionnez-le et cliquez sur **Supprimer l’élément**
   dans son formulaire.
4. Validez chaque modification en cliquant sur **Appliquer** ; cliquez sur **Annuler**
   pour rejeter toutes les modifications effectuées depuis la dernière ouverture de la fenêtre.

## Modifier ultérieurement

1. Ouvrez à nouveau les paramètres du widget. La fenêtre affiche les
   éléments existants et l’image sélectionnée.
2. Sélectionnez dans la liste de gauche l’élément à modifier et modifiez
   son formulaire à droite.
3. Pour remplacer l’image, cliquez sur **Choisir une autre image…**.
   Les éléments sont conservés ; vérifiez ensuite si leur position sur la
   nouvelle image est toujours correcte.
4. **Appliquer**, enregistrer, vérifier dans l’aperçu.

## Dans le Content Designer

Le Content Designer (nouvel éditeur de pages) dispose de son propre
formulaire de téléchargement d’image. L’image est donc sélectionnée à cet endroit, et non dans la
fenêtre des points :

1. Ouvrez les paramètres du widget. Si aucune image n’est encore sélectionnée,
   la fenêtre des points reste fermée et est remplacée par le bouton
   **Modifier les points…**.
2. Sous **Image**, sélectionnez ou téléchargez une image.
3. Sous **Texte alternatif**, indiquez ce qui est représenté sur l’image.
4. Cliquez sur **Modifier les points…** et placez les points comme décrit dans le
   cas de base à partir de l’étape 5.
5. Pour remplacer l’image, fermez la fenêtre des points, remplacez
   l’image dans le formulaire sous **Image**, puis rouvrez la fenêtre.

## Mode « Menu » : placer des éléments de menu

1. Dans les paramètres, sous **Mode**, sélectionnez l’option « Menu :
   placer des éléments de menu sur l’image ». Les champs du mode manuel
   disparaissent, ceux du mode menu apparaissent.
2. Sous **Point de départ dans le menu**, sélectionnez l’élément de menu dont
   les sous-éléments doivent apparaître sur l’image. S’il ne figure pas dans la liste,
   sélectionnez **Saisir un autre ID de menu…** et insérez l’adresse de la page
  .
3. Sous **Niveaux**, définissez la profondeur du menu. La valeur par défaut
   est 3 : le point de départ, ses sous-rubriques et les sous-rubriques de celles-ci.
4. Sous **Clic sur un élément**, choisissez si un clic ouvre la page
   (par défaut) ou si le menu fait défiler les éléments à côté de l’image.
5. Cliquez sur **Placer les éléments de menu…**. À gauche se trouve l’image, à droite
   l’arborescence du menu.
6. Sélectionnez un élément de menu à droite et cliquez à l’endroit souhaité
   sur l’image. Son élément s’affiche à cet endroit ; dans l’arborescence, l’entrée est alors
   marquée de la mention « sur l’image ».
7. Répétez l’étape 6 pour chaque élément de menu supplémentaire. Pour déplacer un élément,
   faites-le glisser ou sélectionnez-le puis cliquez à
   l’emplacement souhaité. **Supprimer l’élément** le fait disparaître de l’image.
8. Cliquez sur **Appliquer**, enregistrez la page et vérifiez le
   résultat dans l’aperçu.

Si vous avez modifié le point de départ ou les niveaux, fermez la fenêtre puis
rouvrez-la — elle lit les deux à l’ouverture.

## Si quelque chose ne fonctionne pas

1. **Le widget n’affiche rien.** Soit l’image manque, soit aucun
   point n’a encore été défini. Ouvrez les paramètres et vérifiez ces deux éléments.
2. **Il est impossible de cliquer sur « Appliquer ».** Au moins un point n’a pas encore
   de titre. La fenêtre indique en bas le nombre de points concernés —
   saisissez-y un titre pour chacun d’entre eux.
3. **La page liée n’apparaît pas dans la fenêtre, mais s’ouvre dans un
   nouvel onglet.** La destination est une adresse que vous avez saisie vous-même, et non une page de
   la liste. C’est normal : les pages externes ne peuvent souvent pas être
   intégrées dans une fenêtre. Sélectionnez plutôt une page dans la liste,
   si vous souhaitez qu’elle s’affiche dans la fenêtre.
4. **La liste des pages ne contient aucune page, mais un champ destiné à
   saisir une adresse.** La liste des pages du système n’était pas
   accessible à l’ouverture. Saisissez l’adresse manuellement ou ouvrez à nouveau la
   fenêtre à nouveau.
5. **En mode « Menu », la fenêtre indique qu’il faut d’abord sélectionner un point de départ
  .** Sous **Point de départ dans le menu**, rien n’est encore sélectionné. Sélectionnez
  un élément de menu, fermez la fenêtre et rouvrez-la.
6. **La fenêtre affiche des éléments sous « N'apparaît plus dans le menu ».** L'élément de
   menu correspondant a été supprimé, masqué ou se trouve à un niveau plus bas que celui défini sous
   **Niveaux**. Ces éléments n'apparaissent pas sur la page.
   Supprimez-les à cet endroit ou augmentez le nombre de niveaux.
